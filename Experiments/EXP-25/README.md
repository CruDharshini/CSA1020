# Experiment 25 – Fork & Implement Feature

1. Fork the original repository.
2. Clone your fork and create `feature-new`.
3. Implement and test a small change.
4. Stage and commit the change.
5. Push the branch to your fork.
6. Open a pull request from your fork to the original repository.

This repository branch contains the experiment instructions; it does not claim an upstream fork or pull request was created.
