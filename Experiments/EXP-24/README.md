# Experiment 24 – Create Feature Login Branch

```bash
git switch -c feature-login
git add Experiments/EXP-24/login.py
git commit -m "Add login functionality"
git push -u origin feature-login
```

Open a pull request from `feature-login` into the target branch and merge after review. The username/password in this lab are hard-coded demonstration values only; never use this pattern for real authentication.
