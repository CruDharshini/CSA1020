# Experiment 09 – Fork & Pull Request Workflow

This folder documents the fork → branch → commit → pull request workflow.

1. Fork a public repository to your account.
2. Clone your fork and create `feature-branch`.
3. Make a small change, commit, and push the branch.
4. Open a pull request against the upstream repository.
5. Review feedback, update the branch, and merge only after approval.

This repository's implementation branch is used for the lab artifacts; no external fork or pull request is claimed here.
